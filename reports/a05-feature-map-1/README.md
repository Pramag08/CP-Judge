## Source boundaries and decisions

- [language_small.json](https://github.com/DMOJ/online-judge/blob/6aaddea6aaeabf4927b83787714509ff9fff8897/judge/fixtures/language_small.json) (18 languages) and [language_all.json](https://github.com/DMOJ/online-judge/blob/6aaddea6aaeabf4927b83787714509ff9fff8897/judge/fixtures/language_all.json) (59) both omit CPP23. The existing worker advertises CPP23, while bridge connection logic filters through database Language records. This is an untested metadata gap to fix/verify during installation; no fixture was modified.

- The candidate imports Django’s default `User`; [Django 4.2.30 auth source](https://github.com/django/django/blob/4.2.30/django/contrib/auth/models.py) has no email uniqueness constraint. Local duplicate-form checks and `associate_by_email` do not establish a race-safe, verified-email invariant. Provider backend verification and all account-creation/change routes require audit.
- Native `ProblemTestCase.batch_dependencies` and compiler support for earlier batches were found. Reuse them where faithful; do not claim group dependencies are wholly absent. In contrast, the stock `CHECKERS` choices omit `bridged`, so manually-managed converted data or a reviewed importer needs explicit evaluation.
- `ContestParticipation.start/end_time` provides the common-clock mapping when `time_limit` is unset. `ContestLeave` clears the active selection, preserving participation; it is not a tested deregistration workflow.
- The ICPC tiebreak and penalty selection differ from the requested preset. IOI16’s per-batch combination is distinct from legacy IOI’s best-submission choice. A10 must select/adapt the actual behavior before publication.
- Existing A02 conversion and A03 isolated judging remain separate evidence. Site database metadata, installation, bridge dispatch, safe statement rendering and browser-to-standings behavior were not exercised here.
- No package/asset installation, service startup, converter changes, judging reruns or independent agents were used for A04/A05. Source absence findings are scoped; third-party auth internals and asset submodule contents remain uninspected.
